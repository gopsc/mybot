# 动作脚本语法规范

bot4cj 使用 `.mt` 矩阵脚本描述机器人。脚本由若干**矩阵对象**组成，每个矩阵对象声明一类硬件或一组动作，解析器读取全部对象后构建硬件变量表，再逐行执行动作矩阵。

`.bot` 为旧版动作脚本格式，仅作兼容保留，新脚本一律使用 `.mt`。

## 词法规则

- 注释以 `#` 开始，至行尾结束。
- 矩阵对象以 `@名字` 行开始，以单独一行 `@` 结束。
- 首行为标题行，定义各列的列名；其后每行为一条数据行。
- 同一行内各列以一个或多个空格、制表符分隔，每行以分号 `;` 结尾。
- 所有数据行的列数必须与标题行一致，否则解析器抛出 `DoesNotSync` 异常。
- 单元格取值 `-` 为占位符，表示继承上一行同列的值（递归向上）；若出现在第一条数据行，按 `0` 处理。

## 内置矩阵对象

| 矩阵对象 | 用途 |
| --- | --- |
| `@Alias` | 定义参数别名 |
| `@I2C` | 声明 I2C 总线设备 |
| `@PCA9685` | 经通用 Lua 驱动加载 PWM 控制板 |
| `@MPU6050_BIND` | 绑定姿态传感器（内置绑定类尚未接入工厂分发，当前走通用 Lua 路径） |
| `@Servo` | 声明舵机 |
| `@Speaker` | 声明扬声器 |
| `@Action` | 动作序列，解析器最终执行的内容 |

除上表所列之外的其他矩阵名一律视为**自定义 Lua 硬件**，详见下文。

### @Alias

为 `@Action` 中使用的参数名定义别名。

```mt
@Alias
name      alias;
   A      angle;
   F  frequency;
@
```

此后动作矩阵中的 `s1.A` 等价于向舵机 `s1` 传入名为 `angle` 的参数。

### @I2C

声明一条 I2C 总线。`path` 为 Linux 设备文件路径。

```mt
@I2C
 name        path;
i2c-0  /dev/i2c-0;
i2c-1  /dev/i2c-1;
@
```

I2C 变量在激活时打开设备文件，退出时关闭；其返回值中的 `fd` 字段可供其他硬件引用。

### @Servo

声明一个舵机。

```mt
@Servo
 name   max  min  offset  controller  channel;
  s1    90     -       -   pca9685-0        0;
@
```

| 列名 | 说明 |
| --- | --- |
| `name` | 变量名，供 `@Action` 引用 |
| `max` / `min` | 角度限幅。取负值时同时表示输出方向翻转 |
| `offset` | 漂移修正量，加在输入角度上 |
| `controller` | 上级控制器变量名，通常指向一个 PCA9685 实例 |
| `channel` | 控制器上的输出通道号 |

设置角度时，先叠加 `offset`，再限制到 `abs(min)` 与 `abs(max)` 之间；若 `max` 为负值则按 `180 - 角度` 翻转后下发。

### @Speaker

声明扬声器。列名须与下表完全一致。

```mt
@Speaker
name  channels  sample_rate  volumn  max_f  min_f;
 spk         2        48000     0.6   5000      -;
@
```

动作中可传入 `frequency`（频率）与 `delay`（毫秒）。频率会被限制到 `[min_f, max_f]` 区间。当前版本的发声调用处于停用状态，该变量实际只承担时序延时的职责。

### 自定义 Lua 硬件

凡未被内置处理的矩阵名，每个数据行都会创建一个硬件变量，并从 `./modules/<矩阵名>.lua` 加载同名驱动脚本。例如：

```mt
@PCA9685
     name    I2C   address;
pca9685-0  i2c-1   0x40;
@
```

构建规则如下：

- 标题行除 `name` 外的各列构成该变量的**元数据**。
- 元数据单元格若与某个已存在的变量名相同，则以该变量的求值结果替换。上例中 `i2c-1` 是已声明的 I2C 变量，其返回的 `fd` 会合并进元数据，Lua 驱动因此能直接拿到总线句柄。
- 驱动脚本需定义三个全局函数：`build(data)`、`call(data)`、`destroy(data)`，分别在硬件构造、每次调用、销毁时被触发，`data` 为合并后的参数表，其中 `mode` 字段标识阶段。

Lua 环境中注册的函数见 [hardware.md](hardware.md#lua-扩展机制)。

### @Action

动作序列是行列式表格。标题行的每个单元格命名为 `设备名.参数名`，数据行依次执行，每行将各列数值同时下发给对应设备。

```mt
@Action
s1.A  s2.A  s3.A  s4.A  spk.F  spk.delay;
  45     -    45     -     10        200;
   -    10     -    10      -         20;
   45     0    45     0     10        200;
@
```

规则：

- 设备名必须与先前声明的硬件变量一致，参数名可经 `@Alias` 换用别名。
- 列命名必须包含且仅包含一个点号，否则抛出异常。
- 占位符 `-` 继承上一行同列的数值，便于只写发生变化的通道。
- 数值按浮点数解析，同一行的所有设备在下一次行执行前同步完成赋值。

## 完整示例

参见仓库内脚本：

- `scripts/std.mt` —— 标准站立姿态
- `scripts/jump.mt` —— 跳跃动作，含完整的硬件声明
- `scripts/tilt-f.mt` 等 —— 倾斜类动作

## 已知限制

- 脚本数值在解析期确定，尚不支持运行时动态计算。
- 自定义硬件的驱动路径固定为 `./modules/`，暂不支持环境变量搜索。
- `@Action` 不支持循环与条件结构，重复动作需复制数据行。
