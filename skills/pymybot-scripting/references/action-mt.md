# 动作脚本（.mt）

技能 `pymybot-scripting` 参考文件。仓库根为 `mybot/`（Python 主线）。
实现：`pymybot/matrix.py`（字符文法）、`pymybot/expr.py`（表达式）、
`pymybot/actions.py`（派发/捕获/控制块/Trigger）、`pymybot/include.py`（Include/Merge）。

## 1. 字符文法

```mt
# 井号到此行末是注释
@Action
relay0.test   timer-0.delay;      # 表头：变量.参数；空白分隔，';' 结行
          1              200;      # 数据行：空白分隔单元格
          2                 -;      # '-' 继承上一行同列
@
```

- 块写成 `@块名`，块名遇空白结束；推荐独占一行，单独一行 `@` 闭块。
- **单元格以空白（空格/Tab/换行）分隔**，`;` 提交一行；一行可以跨多行书写，
  但惯例是一行一拍。空行（连续 `;` 无内容）被忽略。
- 每行单元格数必须等于表头列数。
- CRLF 与 LF 等价；脚本上限 8 MiB；块嵌套深度上限 32。
- 注释 `#` 可以出现在任何位置到行尾（也能结束块名）。
- 分格发生在表达式解析之前，**引号不保护空白、`;` 或 `#`**：`$(n + 1)`、
  `$("hello world")` 不能作为一个单元格。表达式应写 `$(n+1)`；字符串需要 Tab 时可写
  `$("hello\tworld")`，由表达式解析器将 `\t` 转成 Tab，但它不是字面空格。

## 2. @Action 矩阵

**表头**：每个单元格形如 `设备.参数`（源码中恰好一个点，两侧非空；设备名允许连字符，
与 SQL 里 name 列的值一致）。点号两侧可以分别用 `$(...)` 动态生成，如
`$(prefix+n).$(key)`；设备名可再经 `@Alias` 一层间接，参数名渲染为文本。
表头先按点号分割再求值，所以 `dev.$(1.5)` 也不合法。同一 `(设备, 参数)` 解析结果不得重复。
每次派发矩阵时只解析一次表头；同一矩阵后续行的捕获不会改变目标设备或参数名，
循环下一次派发该矩阵时才会重新解析。

**数据行**每格取值（依序判定）：

| 形态 | 语义 |
| --- | --- |
| `-` | 继承上一行同列的原始单元格内容；未设值时的行为见下文 |
| `$(表达式)` | 求值（数字或文本；**不得是布尔**） |
| `$变量=字段.路径` | 捕获：不发送参数，从该设备本次结果中取字段（见第 5 节） |
| 数字字面量 | 十进制或 `0x` 十六进制，严格 Float64 解析 |
| 其他裸文本 | **报错**——文本必须写成 `$("...")` 字符串表达式，或通过 `$(别名)` 读取文本 |

`-` 继承表达式时会重新求值，继承捕获格时会再次调用并捕获，并非复用上次结果。
若设备在整张矩阵中有非 `-` 数据，尚无继承来源的参数会跳过；若该设备的所有数据格
都是 `-`，则每行仍以对应参数值 `0` 调用。继承只在本次矩阵派发内有效，不跨矩阵或循环轮次。

**执行语义**（`actions.py` 的 `dispatch`）：

1. **整行先求值、后派发**：一行所有单元格先算完，捕获值对本行后续单元格不可见，
   从下一行/下一块开始可见。
2. 设备按**表头首次出现顺序串行** `play`；同设备多列合并为本行的一次调用，
   本行没有任何参数也没有捕获的设备跳过。一行不自带固定时长，节拍需由 Timer 等驱动提供。
3. 动作参数不得覆盖保留键：本设备元数据列名、`mode` / `result` / `message`、
   trigger 变量名。
4. 每次调用的返回必须是**非空表**；若含 `result` 键，必须是去掉首尾空白后为 `"OK"`
   的字符串，否则执行失败。设备调用或捕获失败不会撤销此前已发生的调用，一行不是事务。
5. 脚本至少要有顶层 `@Action`、`@if` / `@while` 或 `@Trigger`；只有标量或 Reflex
   定义不能单独运行。条件为假的控制块可以合法地不产生任何调用。

## 3. 表达式语言 `$(...)`

有界解析器（不 eval Python），类型系统：**数字（Float64）/ 文本 / 布尔**，
无隐式真值转换。

| 优先级 | 运算符 | 说明 |
| --- | --- | --- |
| 5 | `*` `/` `%` | 数字；除零/模零报错；`%` 为 C 语义 fmod |
| 4 | `+` `-` | 数字；`+` 任一侧为文本 → 拼接（布尔禁止） |
| 3 | `<` `>` `<=` `>=` | 仅数字大小比较，不支持文本或布尔 |
| 3 | `==` `!=` | 同类型相等比较，支持数字、文本、布尔；跨类型报错 |
| 2 | `&&` | 布尔，惰性 |
| 1 | `\|\|` | 布尔，惰性 |
| 一元 | `-` `!` `+` | 前缀可叠加按奇偶折叠 |

- 表达式字面量：十进制（支持小数、`e` 指数）、`"字符串"`（转义仅 `\n \t \r \\ \"`）。
  **表达式不支持十六进制**：`$(0x10)` 报错；裸数值单元格或 `@Vars` 的裸数值才支持
  `0x10`、`0x1.8p+2`。非有限数值拒绝。
- 标识符解析：`@Vars` → 数字，`@Alias` → 文本；不能直接访问驱动或 `设备.字段`，
  需先捕获字段。标识符只能含字母、数字、下划线且不能以数字开头，连字符会被当作减号。
- `true` / `false` 不是内建布尔字面量；布尔值可由比较表达式产生。
- 单个 `=` 不是运算符（等号必须写 `==`）；不支持 `1<2<3` 式连锁比较。
- 限额：单表达式 ≤512 个二元运算符、≤128 层括号嵌套；数值结果必须有限。
- 条件必须得到布尔值，`@if(1)` 不合法；动作表头或数据单元格的 `$(...)` 产生布尔即报错。

## 4. 控制块 @if / @while

条件写在**块名里**，紧跟括号、**中间不得有空格**——空格是单元格分隔符，
`@while(count < 3)` 会解析成块名 `while(count` 加两个数据格而报错：

```mt
@Vars
name value;
count 0;
@
@while(count<3)
r.value;
$(count);
$count=reading;
@
```

- `@if(条件)` 为真时执行子块；`@while(条件)` 循环执行子块（含空体死循环防护——
  预算耗尽会打断）。
- 控制块**体内直接写数据行**即隐式子 Action（如上：`r.value` 是隐式表头，
  其后每行是数据行），也可以显式嵌 `@Action` 块或再嵌控制块；普通叶子块不能嵌套其他块。
- `@Alias` / `@Vars` / `@Trigger` / `@Reflex` 只能出现在顶层，不能进控制块——
  循环变量的更新靠**捕获**：上例 `$count=reading` 把 `r` 本次结果的 `reading`
  字段写回 `count`，下一轮条件立即用新值（捕获从下一行/下一块起可见，见第 5 节）。

## 5. 捕获 `$变量=字段.路径`

捕获格写在**数据行**里、对齐到要捕获的那个设备的列（表头格必须是 `设备.参数`，
不能放捕获格）：

```mt
@Action
th0.T;
$t=T;
@
```

- 数据格 `$t=T`：`th0` 本行不收动作参数（仍会被调用一次），其结果表的 `T`
  字段捕获为变量 `t`。路径支持点分多级（`a.b.c`），每段必须存在且父级是表。
- 同一行既要发参数又要捕获：加一列**同设备的另一参数**，如
  `th0.T th0.settle` 配数据行 `$(25) $t=T`——`th0` 收到 `T=25` 调用一次，
  捕获读的是**结果表**里的 `T`（回读值），不是发出的参数。
- 数值捕获自动成为 `@Vars` 型标量，文本捕获成为 `@Alias` 型；
  已存在的 `@Vars` 目标必须捕获到数值字段；不能捕获进驱动/daemon 变量。
- 布尔字段必须捕获到已声明的 `@Alias`（可来自 SQL 结构或 MT），保存为文本
  `"true"` / `"false"`；未声明目标无法推断类型，`@Vars` 目标也不接受布尔。
- 设备带 controller 链时，捕获的是链路最终返回的结果。例如 Relay 转发到 Timer 后，
  可捕获 `slept`；不是直接读取 Relay 的中间结果。捕获字段不存在时，设备调用已经发生。

## 6. 会话标量 @Alias / @Vars

```mt
@Vars
name value;
level 2;
@
@Alias
name alias;
output relay0;
@
```

- `@Vars` 必须有 `name` / `value` 列；`@Alias` 必须有 `name` / `alias` 列。
- 所有顶层标量声明在执行动作前统一注册，写在动作块后面也会提前生效；它们不是顺序赋值语句。
- `@Alias` 可临时覆盖同名标量；`@Vars` 不得与结构变量同名；本次 MT 中重复声明同名
  `@Alias` / `@Vars` 会报错。被 controller/trigger 引用的变量不允许覆盖。
- `@Vars` 的 `value` 若为 `$(...)`，每次读取都重新求值，且只能引用数值型 `@Vars`；
  不能用重复声明或 `$(i+1)` 数据格来赋值，循环更新可通过捕获完成。
- 这里的会话指**一次 `Robot.run`**：成功或失败退出时都会恢复进入前的标量覆盖层，
  不会重置 Lua 驱动状态或撤销设备动作，也不会把捕获值保留到下一次 `run`。
- SQL 结构也支持 Alias/Vars（见 `references/structure-sql.md` 第 6 节），但它们属于
  Robot 结构；MT 声明和捕获属于本次运行的临时覆盖层，生命周期不同。

## 7. @Trigger / @Reflex

以下可配合 `robots/relay-test.sql` 运行，由 Relay 转发给 Timer：

```mt
@Reflex
name  relay0.test;
alarm $(delay);
off   0;
@
@Trigger
trigger;
alarm(delay=2);
off;
@
```

- `@Reflex`：定义表，**第一列必须叫 `name`**；同名行归为一组，其余列拼成一个
  Action 表头。
- `@Trigger`：触发表，必须有 `trigger` 列；每行一次调用 `名字` 或
  `名字(键=值,键2=值2)`（MT 单元格内不能有空白）。键为安全标识符，值为**静态文本**，
  触发期内绑定为 `@Alias`，不会计算表达式或自动转数字；例如 `$(delay)` 读到文本 `"2"`。
- **先执行全部普通 Action 和控制块，再执行 Trigger**，与 Trigger 在文件中的位置无关。
  这不是后台事件监听，也不同于 SQL 结构里的 `trigger` 列。
- 出现 `@Trigger` 时必须恰好一张 `@Trigger` + 一张 `@Reflex`。没有 Trigger 时，
  Reflex 定义不执行也不校验其动作内容，但脚本仍须有可运行的 Action 或控制块；
  只有 Reflex 定义的脚本会报 `No @Action matrix found in the script`。
- 触发参数是触发局部绑定，调用结束后恢复，包括捕获到同名参数的值；其他捕获结果
  可供后续触发使用，但仍受本次 `Robot.run` 的外层作用域约束。

## 8. @Include / @Merge 复用

```mt
@Include
path;
common/head.mt;
@

@Merge
path    phase;
frag/beep.mt  5;
@
```

- `@Include`：列只允许 `path`。**复制**被引文件的矩阵序列到当前位置；只能引用
  **动作脚本所在目录内**的相对 `.mt` 路径（拒绝绝对路径、`..`、反斜杠、冒号、
  软链/junction）；循环引用报错，非递归重复复制合法；只能出现在最外层。
- 顶层 `@Merge`：列允许 `path` 与可选 `phase`（整数，行相位偏移，不是时间或并行执行）。
  从片段合并 `@Alias` / `@Vars` / `@Action`（片段里只允许这三种块加顶层 `@Merge` 引用）：
  - 父脚本显式声明的同名标量覆盖子片段定义；两个兄弟片段的同名标量若没有父级定义覆盖，
    会报重复错误，不是后出现者覆盖前者；
  - Action 按列拼接、按 `phase` 对齐行；两个待合并矩阵的设备表头标识重复即报错；
  - 缺行补 `-`：前部等待首个有效值，尾部则继承并重复调用，不代表停止；
  - 负相位会丢弃片段前部数据行并告警，丢掉全部行则报错；首次引入 Action 且尚无
    主矩阵时，该片段的 `phase` 不生效；
  - 主脚本和各片段分别只取第一张 `@Action`，后续 Action 丢弃并告警。
- `*.once.mt`：顶层 Merge 引用树中，同一解析后的文件路径只合并一次；普通 `.mt`
  重复引用或形成环会报错。Include 不适用 once 语义，重复引用仍会重复复制。
- **控制块内的 @Merge**：指令必须位于要合并的普通矩阵表**之前**，将片段并入随后
  的该表，而不是前一张表；片段只能包含普通矩阵，不能含标量、控制块或 Include/Merge。
  同样只允许 `path`/`phase` 列，不采用顶层 Merge 引用树的 once 去重机制。
- 限额：Include/Merge 合计 ≤32 个引用项、深度 ≤32、累计读取 ≤8 MiB；
  两矩阵合并输出 ≤20000 数据行 / ≤200000 数据格。
