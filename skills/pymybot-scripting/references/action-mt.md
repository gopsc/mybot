# 动作脚本（.mt）

技能 `pymybot-scripting` 参考文件。仓库根为 `mybot/`（Python 主线）。
实现：`pymybot/matrix.py`（字符文法）、`pymybot/expr.py`（表达式）、
`pymybot/actions.py`（派发/捕获/控制块/Trigger）、`pymybot/include.py`（Include/Merge）。

## 1. 字符文法

```mt
# 井号到此行末是注释
@Action
relay0.test   timer-0.delay;      # 表头：变量.参数；空白分隔，';' 结行
          1              200;      # 数据行：空白分隔单元格
          2                 -;      # '-' 继承上一行同列
@
```

- 块以**行首**（前面只允许空白）的 `@` 开始，随后到空白前是块名；单独一行 `@` 闭块。
- **单元格以空白（空格/Tab/换行）分隔**，`;` 提交一行；一行可以跨多行书写，
  但惯例是一行一拍。空行（连续 `;` 无内容）被忽略。
- 每行单元格数必须等于表头列数。
- CRLF 与 LF 等价；脚本上限 8 MiB；块嵌套深度上限 32。
- 注释 `#` 可以出现在任何位置到行尾（也能结束块名）。

## 2. @Action 矩阵

**表头**：每个单元格形如 `设备.参数`（恰好一个点，两侧非空；设备名允许连字符，
与 SQL 里 name 列的值一致）。表头单元格也可以是 `$(...)` 动态生成：
设备列解析结果必须是文本设备名（可再经 `@Alias` 一层间接），参数列渲染为文本。
同一 `(设备, 参数)` 目标不得在表头重复。

**数据行**每格取值（依序判定）：

| 形态 | 语义 |
| --- | --- |
| `-` | 继承上一行同列（从未设值则本行不给该设备发此参数） |
| `$(表达式)` | 求值（数字或文本；**不得是布尔**） |
| `$变量=字段.路径` | 捕获：不发送参数，从该设备本次结果中取字段（见第 5 节） |
| 数字字面量 | 十进制或 `0x` 十六进制，严格 Float64 解析 |
| 其他裸文本 | **报错**——文本必须写成 `$("...")` 字符串表达式 |

**执行语义**（`actions.py` 的 `dispatch`）：

1. **整行先求值、后派发**：一行所有单元格先算完，捕获值对本行后续单元格不可见，
   从下一行/下一块开始可见。
2. 设备按**表头首次出现顺序**依次 `play`；本行没有任何参数也没有捕获的设备跳过。
3. 动作参数不得覆盖保留键：本设备元数据列名、`mode` / `result` / `message`、
   trigger 变量名。
4. 每次调用的返回必须是**非空表**；若含 `result` 键必须恰为 `"OK"`，
   否则整跑失败并带 `message`。
5. 顶层脚本至少要有一个 `@Action`（或 `@Trigger`）块。

## 3. 表达式语言 `$(...)`

有界解析器（不 eval Python），类型系统：**数字（Float64）/ 文本 / 布尔**，
无隐式真值转换。

| 优先级 | 运算符 | 说明 |
| --- | --- | --- |
| 5 | `*` `/` `%` | 数字；除零/模零报错；`%` 为 C 语义 fmod |
| 4 | `+` `-` | 数字；`+` 任一侧为文本 → 拼接（布尔禁止） |
| 3 | `<` `>` `<=` `>=` `==` `!=` | 同类型比较；跨类型报错 |
| 2 | `&&` | 布尔，惰性 |
| 1 | `\|\|` | 布尔，惰性 |
| 一元 | `-` `!` `+` | 前缀可叠加按奇偶折叠 |

- 字面量：十进制、十六进制（可带 `p` 指数）、`"字符串"`（转义仅 `\n \t \r \\ \"`）。
  非有限值拒绝。
- 标识符解析：`@Vars` → 数字，`@Alias` → 文本；其他类型报错。
- 单个 `=` 不是运算符（等号必须写 `==`）。
- 限额：单表达式 ≤512 个运算符、≤128 层括号嵌套；结果必须有限。
- 布尔只能出现在 `@if` / `@while` 条件里；参数单元格的 `$(...)` 产生布尔即报错。

## 4. 控制块 @if / @while

条件写在**块名里**，紧跟括号、**中间不得有空格**——空格是单元格分隔符，
`@while(count < 3)` 会解析成块名 `while(count` 加两个数据格而报错：

```mt
@Vars
name value;
count 0;
@
@while(count<3)
r.value;
$(count);
$count=reading;
@
```

- `@if(条件)` 为真时执行子块；`@while(条件)` 循环执行子块（含空体死循环防护——
  预算耗尽会打断）。
- 控制块**体内直接写数据行**即隐式子 Action（如上：`r.value` 是隐式表头，
  其后每行是数据行），也可以显式嵌 `@Action` 块或再嵌控制块；普通叶子块不能嵌套其他块。
- `@Alias` / `@Vars` / `@Trigger` / `@Reflex` 只能出现在顶层，不能进控制块——
  循环变量的更新靠**捕获**：上例 `$count=reading` 把 `r` 本次结果的 `reading`
  字段写回 `count`，下一轮条件立即用新值（捕获从下一行/下一块起可见，见第 5 节）。

## 5. 捕获 `$变量=字段.路径`

捕获格写在**数据行**里、对齐到要捕获的那个设备的列（表头格必须是 `设备.参数`，
不能放捕获格）：

```mt
@Action
th0.T;
$t=T;
@
```

- 数据格 `$t=T`：`th0` 本行不收动作参数（仍会被调用一次），其结果表的 `T`
  字段捕获为变量 `t`。路径支持点分多级（`a.b.c`），每段必须存在且父级是表。
- 同一行既要发参数又要捕获：加一列**同设备的另一参数**，如
  `th0.T th0.settle` 配数据行 `$(25) $t=T`——`th0` 收到 `T=25` 调用一次，
  捕获读的是**结果表**里的 `T`（回读值），不是发出的参数。
- 数值捕获自动成为 `@Vars` 型标量，文本捕获成为 `@Alias` 型；
  已存在的 `@Vars` 目标必须捕获到数值字段；不能捕获进驱动/daemon 变量。
- 布尔字段需先在结构或 `@Alias` 里声明目标类型，否则报「无法推断捕获类型」。

## 6. 会话标量 @Alias / @Vars

```mt
@Vars
name value;
level 2;
@
@Alias
name alias;
output relay0;
@
```

- `@Vars` 列固定为 `name` / `value`；`@Alias` 为 `name` / `alias`。
- 会话内覆盖同名标量；`@Vars` 不得覆盖结构变量；同名重复声明报错。
- 结构文件里也可以声明同名内建表（见 `references/structure-sql.md` 第 6 节），两处机制一致。

## 7. @Trigger / @Reflex

```mt
@Reflex
name  led.value  buzz.mode;
alarm 1              2;
off   0              0;
@
@Trigger
trigger;
alarm(zone=temp);
off;
@
```

- `@Reflex`：定义表，**第一列必须叫 `name`**；同名行归为一组，其余列拼成一个
  Action 表头。
- `@Trigger`：触发表，必须有 `trigger` 列；每行一次调用 `名字` 或
  `名字(键=值, 键2=值2)`（键为安全标识符，值为**静态文本**——不支持表达式，
  触发期内绑定为 `@Alias`）。
- 出现 `@Trigger` 时必须恰好一张 `@Trigger` + 一张 `@Reflex`；只有 `@Reflex` 没有
  `@Trigger` 则整体惰性跳过（合法）。
- 触发参数是触发局部绑定；捕获写入的其他变量在触发结束后保留。

## 8. @Include / @Merge 复用

```mt
@Include
path;
common/head.mt;
@

@Merge
path    phase;
frag/beep.mt  5;
@
```

- `@Include`：列只允许 `path`。**文本复制**被引文件的矩阵序列；只能引用
  **动作脚本所在目录内**的相对 `.mt` 路径（拒绝绝对路径、`..`、反斜杠、冒号、
  软链/junction）；循环引用报错，非递归重复复制合法；只能出现在最外层。
- `@Merge`：列允许 `path` 与可选 `phase`（整数，行相位偏移；负相位丢行有告警）。
  从片段合并 `@Alias` / `@Vars` / `@Action`（片段里只允许这三种块加嵌套 `@Merge`）：
  - 标量按 `name` 去重，**靠近主脚本的定义胜出**；
  - Action 按列拼接、按 `phase` 对齐行；两个脚本出现同一设备即报错；
  - 多个 `@Action` 只取第一个（有告警）。
- `*.once.mt`：Merge 片段的「只合一次」语义（同名片段多次被 Merge 只生效一次；
  Include 不适用 once 语义）。
- **嵌套 @Merge**：`@Merge` 紧跟一张普通矩阵表时，把片段并入该表（同样只允许
  `path`/`phase` 列）。
- 限额：Include/Merge 合计 ≤32 条、深度 ≤32、累计 ≤8 MiB；
  合并输出 ≤20000 行 / ≤200000 格。
