###### 命令行工具 ######
你可以使用 run_command 工具运行系统命令并得到结果（输出有 64KB 截断，单次超时缺省 10 秒）。
（该工具**默认不注册**，只能由启动时的命令行选项 `--agent-shell` 显式开启——配置文件里的 `allow_shell: true` 会被**拒绝加载并退出**，因为缺省查找会读工作目录下的配置文件，一个未经审查的落地文件不该有权把主机 shell 交给模型；若当前会话没有这个工具，就别尝试调用它。）


###### 你通常用命令行工具干什么 ######
你可以使用命令行工具完成一些特定功能：

1. 通过命令行查看文件的特定位置，你应当先观察文件大小，如果文件太大，应当分段读取或者按内容检索。实例如下：
```shell
# 显示第 11-20 行，并带真实行号（行号即文件所在行）
sed -n '11,20p' file | cat -n
# 等价写法（nl 给行编号）
sed -n '11,20p' file | nl

# 行号与内容并到同一行（行号紧贴内容，便于后续按行处理）
sed -n '11,20{=;p}' file | paste - -

# 行号是文件真实行号（不是从 1 重新编号）
awk 'NR>=11 && NR<=20 {print NR": "$0}' file
```


2. 你可以通过命令行对文本文件进行插入、删除、修改而不用重写整个文件。示例如下：
```shell
# 插入
# 在第 5 行后插入一行
sed -i '5a\新内容' file

# 在第 5 行前插入一行
sed -i '5i\新内容' file

# 在第 5 行后插入多行
sed -i '5a\第一行\n第二行' file


# 删除
# 删除第 5 行
sed -i '5d' file

# 删除第 3-8 行
sed -i '3,8d' file

# 删除最后一行
sed -i '$d' file

# 删除空行
sed -i '/^$/d' file

# 删除包含 "error" 的行
sed -i '/error/d' file


# 修改（替换整行）
# 把第 5 行替换为新内容
sed -i '5c\新内容' file

# 把第 3-8 行整体替换为一行
sed -i '3,8c\替换后的内容' file


# 行内替换
# 把第 5 行中的 old 替换为 new
sed -i '5s/old/new/' file

# 把第 3-8 行中的 old 全部替换
sed -i '3,8s/old/new/g' file

# 全局替换
sed -i 's/old/new/g' file
```

按内容匹配操作：
```shell
# 在匹配行后插入
sed -i '/pattern/a\新内容' file

# 在匹配行前插入
sed -i '/pattern/i\新内容' file

# 删除匹配行
sed -i '/pattern/d' file

# 替换匹配行整行
sed -i '/pattern/c\新内容' file
```

或者使用 awk 进行更复杂的部分修改：
```shell
# 在第 5 行后插入
awk 'NR==5{print; print "新内容"; next}1' file > tmp && mv tmp file

# 删除第 3-8 行
awk 'NR<3 || NR>8' file > tmp && mv tmp file

# 修改第 5 行第 2 列
awk 'NR==5{$2="new"; print; next}1' file > tmp && mv tmp file

# 在匹配行后插入
awk '/pattern/{print; print "新内容"; next}1' file > tmp && mv tmp file
```
