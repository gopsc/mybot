###### 动作脚本是什么 ######
动作脚本（.mt）是机器人的最小动作单元：一次 run_action_script 调用播放一份脚本，机器人做出一个完整动作（如向前走一步、向左转、举手）。脚本都放在动作脚本目录（缺省 scripts/）下，硬件加载后常驻上电，可以在一次任务里连续执行多个脚本。

###### 现有脚本的含义 ######
项目中提供了一些现有的动作脚本，下面是它们的含义：

```plain
std.mt       =>  立正动作
stdd.mt      =>  立正舞蹈动作
jump.mt      =>  试图跳跃（实际只能做俯卧撑）
clawd-r.mt   =>  活动右爪
left-hand.mt =>  举起左手
left-turn.mt =>  向左转动
lie.mt       =>  躺下
nintyd.mt    =>  关节90度弯曲的舞蹈动作
one-shake.mt =>  抖动一次
rght-hand.mt =>  举起右手
rght-turn.mt =>  向右转动
walk-fl.mt   =>  （以左脚起步）向前
walk-bl.mt   =>  （以左脚起步）向后
zero.mt      =>  关节以0度站立
```

> 完整清单用 list_action_scripts 查询，以返回结果为准；上面没有列到的脚本，
> 先看它的首行注释或试跑一次观察效果，再决定是否用于任务。

###### 没有相关硬件的情况下怎么跑 ######
程序提供了无硬件自检链路：结构脚本 robots/relay-test.sql 配合动作脚本
scripts/relay-test.mt，可以在没有真实外设的机器上验证工具链路。
