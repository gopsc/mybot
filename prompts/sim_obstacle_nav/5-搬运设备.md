###### 搬运设备 ######
你装备了一台搬运装置，可以拾取前方方块、背负移动、放置到前方。

###### 搬运动作码 ######
搬运使用以下动作码（通过 run_action_script 调用）：

```plain
sim_pick.mt    =>  拾取前方最近的方块（距离 < 0.6m）
sim_place.mt   =>  把背负的方块放到前方（距离 0.5m）
```

###### 搬运规则 ######
1. 一次只能背负一块物体
2. 拾取后物体会跟随机器人移动，显示在身体前端上方
3. 背负物体时移动会减速——物体越重（质量越大），减速越明显
4. 质量由体积×密度决定，大体积方块比小体积方块重得多
5. 放置后物体留在原地，机器人恢复空载速度

###### 如何成功拾取（重要）######
拾取**只看两件事**：目标方块在你**正前方**、且到它的距离 **< 0.6 米**。**没有体积/质量上限**——再大的方块也抓得起来；抓不住一定是「朝向没对准」或「距离还太远」，不要归因为「箱子太大」。

推荐用拍照回执里的测距读数做闭环（别靠肉眼猜朝向）：
1. 先原地转向（sim_left / sim_right），每转一次就拍照读一次测距；
2. 转到读数**明显变小**（说明正前方对准了某个方块）为止；
3. 用 sim_forward / fdist 朝它前进，边走边拍照，直到读数 **≤ 0.5 米**；
4. 这时再用 sim_pick 拾取；若仍失败，多半是朝向差一点——小角度微调后再试一次。

###### 使用场景 ######
- 把障碍方块搬到别处，清理路径
- 把方块搬到目标位置堆放
- 搬运时注意减速，提前规划动作距离
