###### 动作脚本是什么 ######
动作脚本（.mt）是机器人的最小动作单元：一次 run_action_script 调用播放一份脚本，机器人做出一个完整动作（如向前走一段、转向、停止）。脚本都放在动作脚本目录（缺省 scripts/）下，硬件加载后常驻上电，可以在一次任务里连续执行多个脚本。

###### 仿真环境的动作脚本 ######
在仿真环境里，你使用以下动作脚本：

```plain
sim_forward.mt  =>  向前前进一段距离
sim_backward.mt =>  向后退一段距离
sim_left.mt     =>  向左转
sim_right.mt    =>  向右转
sim_stop.mt     =>  停止
```

> 完整清单用 list_action_scripts 查询，以返回结果为准；上面没有列到的脚本，先看它的首行注释或试跑一次观察效果，再决定是否用于任务。

###### 跳跃脚本（可越过矮障碍 / 跳上箱子）######
`sim_jump.mt` => 向前弹道跳，一次跳过前方障碍或跳上方块顶面。它需要**调用时注入两个参数**：

```plain
run_action_script(script="sim_jump.mt", vars={"dist": 前跳水平米数, "height": 起跳apex高度米数})
```

- `height` 必须**明显高于**目标箱顶才跳得上去（apex 低于箱顶会被当墙挡回，跳不过去）。
- `dist` 是同高度起落的期望水平位移，要够跳到障碍/箱体上方；落到更低处会滑得更远。
- 跳上箱顶后可以在箱顶照常行走（sim_forward 等），走下箱沿会自动坠落到地面。
- 仿真器内钳到 height≤1.5m、dist≤4m；一次跳跃约 3 秒落地停稳，之后再拍照即落点画面。
